y oro cepillado, biseles mecánicos refinados y pequeñas lámparas cian, círculo
central completamente hueco y transparente, contorno aislado sobre alpha real,
sin fondo, texto, números, monedas, nave, ranuras o escena. Material pictórico
hard-surface coherente con las naves y UI aprobadas; no recrear botones enteros
con texto ilegible. Marco fijo con disco DOM animado por debajo.
